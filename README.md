# SkillCraft technology - data science task 1
# tool used 
- power bi
# dataset
- sample train dataset containing age values
# description
- in this task, a bar chart was created in power bi to visualize the distribution of people across diffrent age groups.
the continuous age data was grouped into bins to better understand how the population is spread across various age ranges.
# Visualization
- Chart Type: Bar Chart (Age Distribution)
- X-Axis: Age Groups (Bins)
- Y-Axis: Number of People (Count)
# Insight
- The visualization shows that the highest number of people fall within the 20–30 age group, indicating a predominantly young and working-age population.
The population count decreases as age increases, with the lowest representation in the elderly age groups.
# Outcome
This visualization helps in understanding demographic patterns and can be useful for population analysis, planning, and decision-making.
